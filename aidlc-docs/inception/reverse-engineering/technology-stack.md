# 技術スタック

## プログラミング言語
- **TypeScript**: CDK インフラ定義用
- **Python (3.9+)**: Lambda プロセッサー用

## フレームワーク
- **AWS CDK (v2)**: IaC フレームワーク
- **Next.js (予定)**: フロントエンド用

## インフラストラクチャ
- **Amazon S3**: オブジェクトストレージ
- **Amazon SQS**: メッセージキュー
- **AWS Lambda**: サーバーレスコンピュート
- **Aurora DSQL**: マルチリージョン分散SQLデータベース
- **Amazon Translate**: 機械翻訳サービス
- **Clerk**: 認証プラットフォーム

## ビルドツール
- **npm**: パッケージ管理
- **pip**: Python ライブラリ管理
- **Makefile**: タスクランナー

## テキスト処理・変換ツール
- **pdf2image**: PDF to WebP 変換
- **Ghostscript**: pdf2image のバックエンド
- **PyMuPDF (fitz)**: 高速なテキスト抽出
